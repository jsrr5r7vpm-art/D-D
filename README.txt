GRIMOIRE DE THERKOS — APPLICATION WEB

Contenu :
- index.html : application complète, autonome, responsive.
- manifest.webmanifest : métadonnées PWA.
- sw.js : cache de base pour l'accès hors ligne après première visite.

Publication GitHub Pages : déposer les fichiers à la racine du dépôt, avec index.html à la racine.
Données : enregistrées dans le navigateur via localStorage. Utiliser « Exporter sauvegarde » régulièrement. La sauvegarde n'est pas synchronisée automatiquement entre appareils.
Les données de règles marquées « à vérifier » sont volontairement laissées comme telles jusqu'à validation par le MJ.
