GRIMOIRE DE THERKOS — VERSION 17

Cette version ajoute un compteur interactif pour Lueur protectrice (Domaine de la Lumière), restauré après un repos long, et conserve les illustrations des sorts.

AJOUTER THERKOS NIVEAU 3 SANS ÉCRASER LE NIVEAU 2 :
1. Déployer tous les fichiers de cette archive sur GitHub Pages (remplacer les anciens fichiers et le dossier spell-art).
2. Ouvrir l’application, actualiser avec Ctrl+F5.
3. Utiliser Importer et choisir Therkos_Dimitry_Niveau_3.json. Le personnage niveau 3 est ajouté comme une fiche séparée ; la fiche niveau 2 et les données existantes restent conservées.

Compteurs niveau 3 : PV 24/24, dés de vie 3d8, carreaux 20/20, emplacements niveau 1 4/4, niveau 2 2/2, Canalisation divine 2/2, Lueur protectrice 3/3, réputation 1, inspiration héroïque décochée.
