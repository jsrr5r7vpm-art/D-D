GRIMOIRE DE THERKOS DIMITRY — RECONSTRUCTION V1

Contenu :
- index.html : application web complète, responsive, sans dépendance externe.
- manifest.webmanifest : métadonnées PWA.
- sw.js : cache hors ligne versionné.

Publication GitHub Pages : déposer les quatre fichiers à la racine du dépôt avec index.html à la racine, puis Settings > Pages > Deploy from a branch > branche main/principal > /(root).

Données : sauvegarde locale au navigateur. Utiliser « Exporter sauvegarde » pour garder une copie et « Importer » pour restaurer. Le stockage n'est pas synchronisé automatiquement entre appareils.

La campagne L’Odyssée des Seigneurs Dragons et le personnage Therkos Dimitry sont initialisés automatiquement au premier lancement. Si l'application trouve déjà une sauvegarde sans eux, elle les ajoute sans supprimer les autres campagnes.

Les éléments de fiche connus sont préremplis. Les contradictions (Mytros/Kyrah) et règles de satyre/domaines/sorts dépendantes de la version sont signalées dans la fiche et ne doivent pas être considérées comme validées sans le MJ.
